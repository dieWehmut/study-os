# 自定义 AI 模型与侧栏本地品牌设计

## 状态

设计已获用户确认。实现直接在 `main` 分步提交，不创建新分支或工作树。

## 背景

设置页的 AI 服务商编辑器目前使用只读式预设下拉框。后端已经把模型值作为普通字符串写入 `.env.local`，但前端只能从服务商返回的两个模型值中选择，无法配置服务商新发布的模型、私有部署模型或代理层模型。

左侧栏的个人资料组件从 GitHub 公开头像端点加载 `dieWehmut` 的图片。外部页面/资源不可用或被错误解析时，用户会看到网站内容而不是稳定的应用头像；侧栏也因此依赖外网。

## 目标

- AI 设置中的“模型”和“推理模型”都可以直接输入任意非空模型标识。
- 保留服务商返回的现有模型作为输入建议，不改变现有保存 API 和 `.env.local` 格式。
- 模型值保存前去除首尾空白，空输入继续表示“不提交该字段”，避免意外覆盖已有配置。
- 侧栏不再请求或展示 GitHub 用户头像，也不再把 `dieWehmut` 作为侧栏资料来源。
- 使用本地、代码原生的学习系统品牌块/图标，离线时外观稳定且继续链接到首页。
- 为两个行为分别添加回归测试，并保持现有设置、布局和导航测试通过。

## 非目标

- 不新增 AI 服务商、模型探测或远端模型列表 API。
- 不改变后端模型解析、环境变量命名、API 响应结构或模型校验策略。
- 不生成或引入位图头像；本次视觉元素使用现有 lucide 图标和 CSS。
- 不删除发布清单中的 GitHub Release 下载地址；它与侧栏头像无关。
- 不改变侧栏导航路径、移动抽屉行为或其他设置字段。

## 方案选择

### AI 模型输入

采用原生可编辑 `<input>` 配合 `<datalist>` 建议项：

1. `vendor.models` 继续作为建议值来源。
2. “模型”和“推理模型”各自是受控文本输入，用户可选择建议或键入任意模型名。
3. 保存逻辑对草稿执行 `trim()`；空字符串不放入请求体，非空字符串按用户输入发送。
4. 每个服务商使用带服务商 ID 的唯一 `list` ID，避免多个编辑器展开时建议项互相串用。

没有采用以下方案：

- 增加“自定义模型”开关：会让用户多一次模式切换，而且不必要地隐藏了可编辑能力。
- 只换成没有建议的文本框：虽然能输入任意值，但会丢失当前预设的快速选择体验。
- 扩展后端模型目录：模型名称已经是用户配置数据，目录同步会增加网络依赖和新的失败面。

### 侧栏品牌块

移除 `githubUser`、`githubAvatarURL` 以及图片加载/失败回退逻辑。侧栏原头像位置改为固定尺寸的本地品牌块：使用现有 `BookOpen`（或同一图标库中语义等价的学习图标）和“学习系统”文字；外层仍是到 `/` 的 `Link`，保留键盘焦点样式和移动端 `onNavigate` 回调。

这样不会有 `<img>` 网络请求，也不会出现把 HTML 页面当图片内容渲染的问题。`profile.ts` 若仅剩无调用的头像工具，则一并删除；若存在其他调用，保留并缩减为与侧栏无关的纯工具，避免无意义的公共 API。

## 组件与数据流

### AI 配置

`SettingsPanel` 从 `useSettingsStore.vendors` 取得服务商状态。打开某服务商编辑器时，现有草稿状态继续清空；输入框的 `value` 绑定 `modelDraft`/`reasoningModelDraft`，`onChange` 更新草稿，`list` 指向该服务商的建议 `<datalist>`。点击保存时，前端构造现有 `VendorConfigInput`：

```text
modelDraft.trim() !== ""       -> { model: trimmed }
reasoningModelDraft.trim() !== "" -> { reasoning_model: trimmed }
otherwise                       -> omit field
```

`saveVendorConfig` 和后端 `handleAgentConfig` 保持不变；后端已有 `strings.TrimSpace`，并会把值写入对应环境变量及内存配置。保存成功后，store 继续刷新服务商列表，因此新模型会立即显示。

### 侧栏

`SidebarProfile` 渲染本地图标和品牌文本，不再维护 `avatarUnavailable` 状态。尺寸常量可留在组件内，或复用现有布局尺寸；链接、无障碍名称和导航回调保持明确且稳定。

## 错误处理与边界

- 只输入空格的模型名视为空，不发送字段；不会把空模型写入环境文件。
- 模型标识中的内部空格、斜杠、冒号和版本符号按原样保留，只清理首尾空白。
- 建议列表为空时输入框仍可用，覆盖没有预设的新服务商配置场景。
- GitHub 不可访问不会影响侧栏渲染，因为实现不再发起请求。
- 保留现有 API 错误提示和保存中的禁用状态，不新增静默失败。
