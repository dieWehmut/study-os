# 桌面侧栏隐藏与内容区间距设计

## 目标

让桌面端侧栏可以完全隐藏，隐藏后内容区立即占用释放的横向空间；开关位于页头主题按钮左侧，并保持移动端抽屉导航行为不变。

## 行为

- 桌面端默认显示侧栏。
- 页头提供“隐藏侧栏”或“显示侧栏”图标按钮，按钮紧邻主题切换按钮左侧。
- 状态写入 `localStorage`，刷新页面后恢复上次选择；读取失败时回退为显示。
- 侧栏隐藏时从桌面布局和无障碍树中移除，主内容由 `md:pl-64` 切换为 `md:pl-0`。
- 移动端菜单按钮、抽屉、遮罩和导航关闭逻辑不改变。
- 桌面页头、静态模式提示条和主内容的大屏水平内边距从 `lg:px-8` 收紧为 `lg:px-5`，减少侧栏与内容的视觉空隙。

## 组件边界

- `AppShell` 持有桌面侧栏可见性状态和持久化逻辑。
- `Header` 只接收状态与回调，负责按钮顺序、标签和键盘/屏幕阅读器语义。
- `Sidebar` 接收隐藏状态并通过 `id="desktop-sidebar"` 提供控制目标。

## 验证

- 测试按钮默认位于主题按钮左侧，具有 `aria-expanded`、`aria-controls` 和相反的显示/隐藏标签。
- 测试切换会更新主内容的桌面 padding、侧栏 `aria-hidden` 和本地存储。
- 测试刷新挂载时能恢复隐藏状态。
- 测试移动抽屉仍由原菜单按钮独立控制。
